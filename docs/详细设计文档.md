## 1. 概述

### 1.1 范围

### 1.2 概要设计开放问题的定稿结论

| # | 开放问题 | 定稿结论 | 理由 |
| --- | --- | --- | --- |
| 1 | 原生窗口选型 | **Electron + electron-builder**（纯 TS/JS，无 Rust），产出 NSIS 安装版 + 便携版 | 与 TS 全栈一致、出安装器最省事；体积大可接受（桌面后台工具）。Tauri 留作后续轻量化备选 |

| 3 | `node:sqlite` flag | 基线定 **Node 24 LTS**（`node:sqlite` 默认稳定，免 `--experimental-sqlite`） | 免原生模块打包 |

## 4. 数据层设计（db）

### 4.1 Database 单例

```ts
import { DatabaseSync } from 'node:sqlite';

export class Database {
  private db: DatabaseSync;
  static instance: Database;
  static open(path: string): Database {
    const db = new DatabaseSync(path);
    db.exec('PRAGMA journal_mode = WAL');
    db.exec('PRAGMA foreign_keys = ON');
    Database.instance = new Database(db);
    return Database.instance;
  }
  exec(sql: string): void { this.db.exec(sql); }
  prepare(sql: string) { return this.db.prepare(sql); }
  getUserVersion(): number { return this.prepare('PRAGMA user_version').get().user_version; }
  setUserVersion(v: number): void { this.exec(`PRAGMA user_version = ${v}`); }
  close(): void { this.db.close(); }
}
```

> 采用同步 API（`DatabaseSync`），契合 `node:sqlite` 的单线程模型；写操作均封装在迁移/Repo 内，避免异步竞态。

### 4.2 迁移器（`migrate.ts`）

```ts
interface Migration { version: number; name: string; sql: string; }

export function migrate(db: Database, migrations: Migration[]): void {
  const cur = db.getUserVersion();
  if (cur > 0) backupDb(dbPath);          // 升级前备份 client.db.bak.<ts>
  const pending = migrations.filter(m => m.version > cur).sort((a,b)=>a.version-b.version);
  for (const m of pending) {
    db.exec('BEGIN');
    try {
      db.exec(m.sql);
      db.setUserVersion(m.version);
      db.exec('COMMIT');
    } catch (e) {
      db.exec('ROLLBACK');
      throw new Error(`迁移 ${m.name} 失败：${e.message}`);   // 不进入运行态
    }
  }
}
```

```ts
**resumeAll 恢复逻辑**（服务启动时调用，`main()` 在 HTTP 监听前执行）：
1. 读取 `connection` 表 `status='running'` 的连接记录。
2. 逐条：解析 `config_json` → 构建 `ConnectionRuntime` → **自动调用 `connector.connect()`**（沿用上次运行态）。
3. 恢复失败：该连接 `status='error'`、写 `connection_event` 与日志，**不阻塞整体服务启动，也不影响其他连接恢复**。
4. `main()` 对该方法整体 `try/catch`，异常仅告警不抛出。
```


- **SeenMessages**（`seen.ts`）：`firstTime(msgId): boolean`，TTL 600s、容量 5000，每连接器实例独立。
  - **淘汰策略（惰性）**：每次 `firstTime()` 调用时，先弹掉队首 `now - ts > TTL` 的过期条目，再在 `size >= max` 时淘汰最旧条目（用保序 `Map`）。无定时器，均摊 O(1)。

## 7. 核心链路（pipeline，每连接独立）

### 7.1 Pipeline 主流程（`index.ts`）

```ts
export class Pipeline {
  constructor(private rt: ConnectionRuntime, private deps: RuntimeDeps) {}

  async handle(m: NormalizedMessage): Promise<void> {
    const r = this.rt;
    try {
      // ① 触发决策 [P1]：P0 固定仅 @ 回复
      if (!TriggerDecision.should(m, r.config.chat.trigger)) { r.status; return; }
      // ② 白/黑名单
      if (!AccessControl.allow(m, r.config.chat)) { emit({kind:'log',...}); return; }
      // ③ 上下文（getOrCreate 保证首次对话也有 buffer，避免 push 丢失）
      const key = ctxKey(m);
      const buf = r.context.getOrCreate(key);
      const history = buf.recent();
      // ④ 安全(入)
      const clean = SafetyFilter.in(m.content, this.deps.globalBanwords, this.personaBanned);
      if (clean.rejected) { await Reply.reject(r, m, 'refuse'); return; }
      // ⑤ 组装
      const prompt = PromptBuilder.build(this.persona.profilePrompt, history, clean.text);
      // ⑥ LLM
      const res = await this.deps.llm.complete(prompt);
      // ⑦ 安全(出)
      const out = SafetyFilter.out(res.text, this.deps.globalBanwords, this.personaBanned);
      // ⑧ 回复 + 打点
      await Reply.send(r, m, out, res);
      // 上下文更新（写入已 getOrCreate 的 buffer，首次对话也能正确入栈）
      buf.push({ role: 'user', content: m.content }, { role: 'assistant', content: out });
    } catch (e) {
      await Reply.send(r, m, FALLBACK, { ok:false, error:String(e) });
    }
  }
}
```

### 7.2 各步骤类

```ts
class TriggerDecision { static should(m, mode: TriggerMode): boolean; } // P0: mode==='at' ? m.atBot : ...
class AccessControl {
  static allow(m, chat: ChatConfig): boolean;
  // mode=whitelist: groupList/userList 命中才放行；blacklist: 命中则拒绝
}
class ContextBuffer {
  private buf: Array<{role:string;content:string}> = [];
  push(...items): void;   // 超出 contextMaxMessages 截断头部
  recent(): Array<{role,content}>;
  expired(ttlMin: number): boolean;
}
class ContextManager {
  private store = new Map<string, ContextBuffer>();
  getOrCreate(key): ContextBuffer;   // 首次对话自动创建并返回（修复 push 丢失）
  get(key): ContextBuffer | undefined;
  gc(): void;                        // 定时清理过期 buffer
  clear(): void;                     // 停止连接时整体释放
}
class SafetyFilter {
  // global 参数为 BanwordRepo.getCache() 返回的内存缓存（Set），非 DB 查询
  static in(text, global: CachedBanwords, persona: string[]): { text: string; rejected: boolean };
  static out(text, global: CachedBanwords, persona: string[]): string; // 命中替换兜底
  static redactPii(text): string;   // 手机号/身份证脱敏
}
class RateLimiter {
  constructor(private cfg: RateLimitConfig) {}
  allow(): boolean;                 // 单位时间最大回复次数 / 最小间隔
}
class TokenBudget {
  constructor(private connectionId: string, private limit: number) {}
  load(): void;                     // 从 token_budget 表加载「今日」计数到内存
```

### 9.2 预检实现（阻塞/警告）

```ts
async function precheck(id): Promise<PrecheckResult> {
  const cfg = getConfig(id); const items: PrecheckItem[] = [];
  // credential（block）
  items.push(cfg.type==='official'
    ? check(cfg.official?.appId && cfg.official?.appSecret, 'credential', '连接凭据不完整：请填写 AppID/AppSecret')
    : check(cfg.account?.host, 'credential', '连接凭据不完整：请填写 OneBot 地址'));
  // dependency（block）
  items.push(await checkDependency(cfg.type, '依赖不可用：请安装官方 SDK / 启动 NapCat'));
  // persona（block）
  items.push(check(await personaRepo.get(cfg.personaId), 'persona', '绑定人格无效：请重新选择人格'));
  // llm（warn）
  const llm = resolveLlm(cfg);   // llmOverride > 全局
  items.push(llm.apiKey ? await testLlm(llm) : warn('llm', '未配置 LLM apiKey，将使用演示模式'));
  return { ok: !items.some(i => i.level==='block' && i.status==='fail'), items };
}
```

## 10. 日志模块（log.service.ts）

- 结构：`{ ts, level, source: 'server'|'connector'|'llm'|'pipeline', connectionId?, msg, meta }`，全局递增 `seq`。
- 内存：环形缓冲 4000 行（`ArrayDeque`）。
- 文件：`data/logs/<connectionId|server>/<source>/YYYY-MM-DD.log`，按天滚动。
- **文件写失败降级**：写文件 `try/catch`；磁盘满/权限不足时丢弃文件写入、仅保留内存缓冲 + WS 推送；连续失败 ≥10 次则暂停后续文件写入并记一条 error（避免反复失败），每 5 分钟重试一次；日志失败绝不影响主流程。
- WS：`/ws/logs` 增量推送 `{ seq, entry }`，前端用 `since` 游标续传。

```sql
-- 时段 token 消耗（今日按小时）
SELECT strftime('%H', ts/1000,'unixepoch') AS hour,
       SUM(prompt_tokens) AS prompt, SUM(completion_tokens) AS completion
FROM llm_call WHERE connection_id=? AND ts>=? GROUP BY hour ORDER BY hour;

-- 成本（今日，按模型）
SELECT model, SUM(prompt_tokens) AS p, SUM(completion_tokens) AS c
FROM llm_call WHERE connection_id=? AND ts>=? GROUP BY model;
-- 费用 = Σ (p_i × inputPrice_i + c_i × outputPrice_i) / 1e6
```

```ts
export async function checkRelease(owner: string, repo: string, pat?: string): Promise<ReleaseInfo|null> {
  const url = `https://api.github.com/repos/${owner}/${repo}/releases/latest`;
  const headers = { 'User-Agent': 'QQAiChatBot', ...(pat ? { Authorization: `token ${pat}` } : {}) };
  // fetch 超时 5s；非 200（含 401）返回 null
  const j = await fetch(url, { headers, signal: AbortSignal.timeout(5000) }).then(r => r.json());
  return { version: j.tag_name, changelog: j.body, assets: j.assets.map(a => ({ name: a.name, url: a.browser_download_url })) };
}
```

## 19. 错误码规范

| code | 语义 | 典型场景 |
| --- | --- | --- |
