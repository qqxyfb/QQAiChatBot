# QQAiChatBot v0.1.0

基于 LLM 的 QQ 聊天机器人后台客户端首个可用版本。单进程 TS/Node.js 服务，Web 控制台管理多个连接，每个连接独立配置人格、名单、流量控制与 LLM。

## 下载

| 产物 | 适用场景 | 说明 |
| --- | --- | --- |
| `QQAiChatBot-Setup-0.1.0-x64.exe` | Windows 10/11 | NSIS 安装版：可选安装目录、桌面/开始菜单快捷方式、控制面板卸载、覆盖升级保留数据 |
| `QQAiChatBot-Portable-0.1.0.exe` | Windows 10/11 | 便携版：单文件免安装，数据存 exe 同级 `data\` |
| Source code (zip / tar.gz) | Linux / 自行构建 | Linux 以源码 + systemd 后台运行（见下方「Linux 部署」） |

每个 exe 附带 `.sha256` 校验文件，客户端「检查更新」下载后会自动校验。

## 主要功能

**运行形态**
- Windows：exe 启动后拉起本地服务并打开原生窗口（Electron），也可直接用浏览器访问 `http://127.0.0.1:8700`
- Linux：纯后台进程 + systemd，通过页面访问
- 更新检测：对接 GitHub Release（`releases/latest`），支持下载升级包并做 SHA256 校验
- 系统托盘常驻（关闭窗口最小化到托盘）

**多连接后台**
- 客户端作为总后台，可建立多个连接，默认上限 20（可配）
- 每个连接独立：连接属性、绑定人格、白/黑名单、上下文条数、每日 token 预算、限流、触发规则、LLM 覆盖
- 连接级启停 + 全部启停 + 一键复制连接
- 启动预检：凭据/依赖/人格为阻塞项，LLM 连通为警告放行，失败逐项返回原因

**接入方式**
- QQ 官方机器人（AppID + AppSecret，WebSocket + REST）
- 登录 QQ 号（OneBot v11，支持正向/反向 WS，可对接 NapCat 等实现）
- 选择「登录 QQ 号」需在页面确认知晓封号风险

**人格管理**
- 人格作为全局资源池，一个人格可被多个连接引用
- 导入 / 在线生成 / 在线编辑 / 导出 / 删除
- 内置默认人格与格式帮助文档（无鉴权，可直接生成人格）

**可观测性**
- 运行日志：按连接分目录、WS 实时推送、关键字与级别筛选
- 数据统计：消息与 token 趋势、时段 token 分布、延迟分位、结果分布、Top 消耗对象、分连接对比
- 使用消耗：按模型单价（元/百万 token）折算今日/7 天/30 天费用与月度预估
- 聊天记录：会话列表 + 明细 + 导出，支持从统计 Top 对象下钻

**安全**
- 密钥 AES-256-GCM 加密存储，接口返回脱敏
- 全局违禁词库 + 人格级红线词，双向过滤
- 手机号/身份证等 PII 入站脱敏
- 默认仅监听 `127.0.0.1`；开启外网访问强制要求访问令牌（Bearer 鉴权）

## 安装与首次使用

1. 运行 `QQAiChatBot-Setup-0.1.0-x64.exe` 完成安装（或直接运行便携版）。
2. 打开后进入「核心配置」，填写 LLM 的 Base URL / API Key / 模型，点「测试 LLM」。
3. 进入「连接管理」新建连接，选择接入方式并填写凭据。
4. 进入「人格管理」选择内置人格或导入/生成一个，回到连接里绑定。
5. 点「启动」，在「运行日志」确认连接已建立。

## Linux 部署

```bash
npm ci && npm run build
sudo cp scripts/qqaichatbot.service /etc/systemd/system/
sudo systemctl daemon-reload && sudo systemctl enable --now qqaichatbot
```

默认监听 `127.0.0.1:8700`，通过反向代理或开启外网访问 + 访问令牌对外提供页面。

## 已知限制与注意事项

- **exe 未做代码签名**：首次运行可能触发 SmartScreen 提示，选择「更多信息 → 仍要运行」。
- **仓库当前为 private**：客户端检查更新需要在「核心配置 → 更新」中填写具有 `repo` 读取权限的 GitHub PAT；仓库转为 public 后可留空。
- **登录 QQ 号存在封号风险**：使用第三方协议登录属非官方途径，风险自担；建议优先使用官方机器人。
- **真实 QQ 联调需自行准备**：官方机器人需在 QQ 开放平台开通群 @ / 私聊能力。
- **Linux 未提供预编译包**：本版仅发布 Windows 产物，Linux 走源码部署。
- P2 能力（长期记忆/向量库、图片识别回复、多实例远程、Docker 部署）本版未包含。
