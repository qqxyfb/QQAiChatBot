# QQAiChatBot v0.1.4

功能版：机器人回复从「纯文字」扩展为**富媒体**，新增**表情包**（预制 + 智能两级选择）与**语音**（TTS 多厂商）两类回复能力。

详细设计：[`docs/富媒体回复详细设计文档.md`](../富媒体回复详细设计文档.md) · 剩余项代办：[`docs/TODO-富媒体回复.md`](../TODO-富媒体回复.md)

## 新功能

### 1. 表情包回复

- **表情包库**：本地预制图片文件 + 自维护「标签 → 文件集」映射，按「表情包组」组织，全局资源池、可被多个人格引用（不同人格可用不同组，也可共用）。
- **导入与打标签**：文件名约定自动打标签（`开心_01.png` / `开心/xxx.png`），也可导入后在界面手动增删标签；新增「表情包管理」页。
- **两级选择**：不是关键词写死命中，而是让 LLM 结合上下文输出 `[sticker:标签]`（标签枚举由后端注入提示词、受控），命中标签后在候选文件里**随机取一张**单独发送（不配文字）；非法/无候选自动降级纯文字。
- **人格绑定**：人格编辑页新增「表情包组」下拉，未绑定时回退默认组。

### 2. 语音回复（TTS）

- **多厂商抽象**：`TtsProvider` 接口 + 两个实现——`openai-compatible`（`POST {base}/audio/speech`，覆盖 OpenAI / 硅基流动 / MiniMax 等兼容厂商）与 `edge`（微软 Edge 免费语音，WebSocket 非官方接口）。
- **全局默认 + 人格覆盖**：全局配置页设默认 TTS（厂商/音色/模型/BaseURL/APIKey + 试听）；人格编辑页可开「语音回复」并单独指定音色（未填继承全局）。
- **触发**：人格开启语音回复后，文字回复会自动**附加一条语音**（文字 + 语音都发）；表情包回复不附加语音；TTS 失败自动降级纯文字，不阻塞回复。

### 3. 富媒体消息段模型

- 回复负载新增可选 `segments`（`text / sticker / voice`），向后兼容：缺省时仍按 `content` 发纯文本，旧连接不受影响。

## 技术要点

- 新增 `002_sticker.sql` 迁移（`sticker_set` / `sticker` 两张表，`user_version` 1→2），自动升级、旧库兼容。
- 表情包倒排索引内存缓存（复用 banword 的缓存模式）；表情包/语音不入 LLM 上下文，历史只存纯文本。
- 连接器富媒体发送：OneBot 用 `[CQ:image]` / `[CQ:record]`；官方 Bot 表情包按图片发送（无原生表情类型）。
- 语音不转 silk，直接输出 mp3：OneBot 由 NapCat 自动转码，官方 Bot 上传 mp3。

## 已知限制（详见 TODO-富媒体回复.md）

- **官方 Bot 富媒体消息体结构未联调**：`msg_type:7 + media.file_info` 等字段据文档推断，需真实 AppID/AppSecret 联调确认；语音 mp3 能否被官方 Bot 接受待验证。
- **Edge TTS 为非官方接口**：token/协议可能变化，开发环境实测 `403` 无法验证；建议优先用 `openai-compatible` 配一个兼容厂商。
- exe 未做代码签名，首次运行可能触发 SmartScreen 提示。
