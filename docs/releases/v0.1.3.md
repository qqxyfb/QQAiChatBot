# QQAiChatBot v0.1.3

修复版：解决 v0.1.2 安装后反馈的 4 个问题（私聊无响应、运行日志空白、API Key 回显 `***`、抽屉误关丢内容），
并把代码走查发现的限流维度、并发串行、配置热更新等健壮性问题一并处理。

对应任务单：[`docs/TASKS-2026-10-20.md`](../TASKS-2026-10-20.md)

## 重点修复

### 1. 私聊 Bot 完全没反应（P0）

**原因**：触发规则 `at` 模式下只认 `m.atBot`，而官方 Bot 的私聊事件（`C2C_MESSAGE_CREATE`）本身没有「@」概念，
`atBot` 恒为 `false` —— 私聊消息在进入 pipeline 的第一道判定就被静默丢弃，连日志都不留。

**修复**：`at` 模式下私聊直接放行（`c2c` 无 @ 语义）；`keyword` / `random` 在私聊里语义成立，仍按配置执行。

### 2. 运行日志页永远空白（P0）

**原因**：`LogService` 只消费 `kind:'log'` 事件，而正常链路的 `message` / `llm_call` 只写数据库；
`kind:'log'` 仅在「发送失败」等异常分支产生。于是「一切正常」时日志页必然全空。

**修复**：

- 链路关键节点全部落日志：`收到消息 → 触发通过 → 名单通过 → 调用 LLM → LLM 返回 → 回复已发送`；
- LLM 失败信息（状态码/耗时/重试次数）同步进运行日志，不再只躺在 `llm_call` 表里；
- **早退原因可见**：触发/名单/限流/超长/违禁词拦截都会记一条带原因的 DEBUG/WARN，不再「静默丢弃」；
- **启动回灌**：服务启动时把当日日志文件读回内存缓冲，重启后日志页不再全空。

### 3. 配置页 API Key 变 `***`、二次保存报错（P1）

**原因**：`GET/PUT /api/config` 都做了接口级脱敏，前端把 `***` 当真实值回填，二次保存时又被当成新密钥加密/校验，导致报错。

**修复**：本地桌面应用（默认只监听 `127.0.0.1`）不再脱敏，回显真实值；脱敏只保留在**导出**路径
（`/api/config/export` 默认脱敏，`?reveal=1` 导出明文）。导入脱敏文件时把密钥置空并提示重填，绝不静默沿用本机旧 Key。
配置页密钥输入框增加显隐切换。

### 4. 连接配置抽屉点遮罩就关闭、编辑内容丢失（P1）

**修复**：`maskClosable={false}` + `keyboard={false}`；关闭前做脏检查，有未保存修改时二次确认。

### 5. 强制黑色主题、层次不清（P2）

**修复**：新增浅色 / 深色 / 跟随系统三态切换（顶栏右侧，持久化到 `localStorage`，默认浅色）；
侧边栏、顶栏、卡片改用 AntD token 取色，ECharts 轴线/图例/网格线同样从 token 推导，浅色下不再出现「浅灰文字配白底」。

## 健壮性改进

- **限流按对象分桶**：原来每个连接只有一个计数器，群聊里 A 刷屏会把 B、C 的正常消息一起挤掉；现在默认按对象分桶，可用 `rateLimit.scope='connection'` 回到旧行为。
- **同会话消息串行化**：同一群/对象的消息按到达顺序处理，避免并发跑 LLM 导致回复乱序、上下文交错；积压超过 5 条丢弃并告警。
- **配置热更新**：修改触发规则、上下文条数、限流、token 预算、人格绑定、LLM 覆盖后**无需重启连接**，下一条消息即生效（上下文内容与当日用量保留）。
- **启动前置校验**：启动连接前探测 LLM `/models`（8s 超时，支持代理回退），不可达或模型不存在时直接阻断启动并给出具体原因，不再「running 但静默」；代理不支持 `/models` 时降级为仅探通。
- **日志目录修复**：服务级日志不再落到 `logs/server/server/`。
- **迁移备份策略**：只在真的要执行迁移时备份旧库，避免每次启动都全量拷贝一份 `.bak`。
- **配置快照容错**：快照写入失败（库被锁/只读）不再让「保存」整体报错。

## 回归验证

```bash
npm run build          # 后端 tsc + 前端 vite
npm run smoke          # pipeline / c2c 触发 / 配置读写 / 运行态热更新
npm run e2e            # 用临时数据目录拉起服务做接口级联调
npm run verify:serve   # 前端托管（cwd 无关）回归
```

新增脚本：`scripts/smoke-c2c.cjs`、`scripts/smoke-config.cjs`、`scripts/smoke-runtime.cjs`、`scripts/e2e-check.cjs`。

## 升级须知

- 覆盖安装即可，`%APPDATA%\QQAiChatBot` 下的配置、人格、聊天记录、日志均保留。
- 老版本的日志目录里可能残留 `logs/server/server/`，新日志写入 `logs/server/`，旧文件不影响使用，可手动清理。
- 若此前把触发规则设为「仅 @ 回复」，升级后私聊会开始正常回复；不希望私聊响应请改为「静默」或把对方加入黑名单。

## 已知限制

- exe 未做代码签名，首次运行可能触发 SmartScreen 提示。
- LLM 探测依赖 `GET /models`；部分自建代理不实现该接口，此时只做连通性判断，不做模型名校验。
- 登录 QQ 号（OneBot v11）属非官方途径，存在封号风险。
